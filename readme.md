# 心跳與體循環互動教學系統 (Blood Circulation Interactive System)

專為國中自然科學／生物科設計之互動式數位教具，將微觀心臟作動（收縮期／舒張期瓣膜開閉）與宏觀人體血液／淋巴循環整合於單一頁面，支援大螢幕課堂演示與學生平板觸控操作。

---

## 🌟 核心功能特色

1. **雙重視野對照教學**
   * **微觀心臟剖面**：動態展示心室收縮期（送血至主動脈/肺動脈）與舒張期（靜脈血回流充盈）之明暗對比與瓣膜運作。
   * **宏觀體循環與肺循環**：21 條擬真血流動畫，清楚標示動脈充氧血（紅）與靜脈缺氧血（藍）。

2. **器官生理與淋巴考點互動**
   * 點擊循環圖上對應之器官黑點，右側即時切換生理功能說明。
   * 完整涵蓋會考核心重點：肺臟、肝臟、肝門靜脈、胃、小腸、大腸、胰臟、腎臟、一般微血管。
   * 整合淋巴系統核心概念：微淋巴管盲端（組織液回收）、淋巴結（免疫安檢）、淋巴管單向動力、鎖骨下靜脈（體液回歸）及小腸乳糜管（脂溶性養分吸收特例）。

3. **高彈性自編與校準模式**
   * **路徑與熱區微調**：進入校準模式可直接拖曳調整血管虛線軌跡與器官黑點位置。
   * **講義文字自訂**：可直接於畫面點擊文字區塊編輯解說文案，符合教師個人授課語境。
   * **配置匯出／匯入**：支援一鍵匯出與匯入 JSON 設定檔，換設備或分享給其他教師皆能無痛套用。

## 🚀 本機下載與離線安裝說明

本專案為純前端單一網頁架構，**無需安裝 Node.js、Python 或任何伺服器環境**，下載即可離線使用。

### 步驟說明：

1. **取得專案檔案**
   * 點擊本專案頁面右上角綠色的 **`Code`** 按鈕。
   * 選擇 **`Download ZIP`** 下載壓縮檔並解壓縮至電腦。

2. **確認檔案放置結構**
   請確保以下檔案位於**同一個資料夾**內：
   ```text
   📁 blood-circulation/
   ├── index.html                    (核心網頁)
   ├── heart.jpg                     (心臟剖面圖)
   ├── bloodcirculation.jpg          (全身循環底圖)
   └── circulation-system-v13.json   (預先校準之設定檔)
